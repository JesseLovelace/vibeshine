# 2.0.0-stable.11 (personal fork build)

Unofficial build of Vibeshine 2.0.0 from JesseLovelace/vibeshine with these changes on top of the 2.0.0 release:

- Remote Monitor now honours the client's "play audio on host" setting instead of always playing audio on the host PC's speakers.
- The Remote Monitor layout editor no longer fails to load when Windows reports an inactive display output.
- The Remote Monitor layout editor no longer fails with "Unable to load the display layout." in the browser (reactive data is unwrapped before cloning).
